# ملاحظاتي (NotesLink)

تطبيق ملاحظات محلي بالكامل (بدون تسجيل دخول، بدون إنترنت، بدون خدمات Google) مبني بلغة Kotlin،
مستوحى من تجربة الاستخدام في Google Keep، مع إضافة شبكة علاقات بين الملاحظات (مبنية على وسوم
مثل `#عمل`) على طراز Obsidian.

## المزايا
- بطاقات ملاحظات ملوّنة + بحث فوري
- تخزين محلي بالكامل عبر Room/SQLite — لا حاجة لأي حساب
- نسخة احتياطية: تصدير كل الملاحظات إلى ملف JSON واحد تختار مكان حفظه
- استيراد: استرجاع الملاحظات من ملف النسخة الاحتياطية (دمج أو استبدال)
- شبكة العلاقات: أي وسم تكتبه داخل ملاحظة (مثل `#مشروع`) يربطها تلقائيًا بكل الملاحظات
  الأخرى التي تحمل نفس الوسم، مع نفس عناصر التحكم التي رأيتها في Obsidian: تكبير/تصغير
  باللمس، قوة الوسط، قوة الصد، قوة الرابط، مسافة الرابط، حجم الرأس، سمك الرابط،
  حد تلاشي النص، إظهار الأسهم، وزر "تحريك" لإعادة تشغيل المحاكاة

## كيف تحصل على ملف APK (بدون الحاجة لأي كمبيوتر)
المشروع يحتوي على ملف `.github/workflows/build.yml` يقوم ببناء التطبيق تلقائيًا:

1. أنشئ مستودع (repository) جديد فارغ على GitHub من تطبيق GitHub على جوالك أو من المتصفح
2. ارفع محتويات هذا الملف المضغوط بالكامل إلى المستودع (يمكنك ذلك من تطبيق GitHub
   للجوال عبر "Add file → Upload files"، أو برفع ملف الـ zip ثم فك ضغطه عبر ميزة
   "Upload" في واجهة الويب على الجوال)
3. بعد الرفع مباشرة، اذهب إلى تبويب **Actions** في المستودع — ستجد أن البناء بدأ تلقائيًا
4. عند اكتمال البناء (علامة ✅ خضراء)، افتح تشغيل العملية (run) واسحب لأسفل إلى قسم
   **Artifacts**، ستجد ملف باسم `app-debug-apk` — نزّله (سيصلك كملف zip يحتوي على
   `app-debug.apk` بداخله)
5. فعّل خيار "تثبيت من مصادر غير معروفة" لمتصفحك/تطبيق الملفات في إعدادات أندرويد، ثم
   افتح ملف `app-debug.apk` لتثبيته

هذه نسخة "debug" موقّعة تلقائيًا بمفتاح تطوير قياسي — تعمل بشكل كامل على جهازك الشخصي
كأي تطبيق، لكنها غير مخصصة للنشر على متجر Play.

## هيكل المشروع
```
app/src/main/java/com/notekeep/local/
├── data/     Room (Note, NoteDao, AppDatabase) + BackupManager (تصدير/استيراد JSON)
├── ui/       MainActivity, NoteEditActivity, SettingsActivity, NoteAdapter
└── graph/    GraphActivity, GraphView (رسم ولمس), ForceSimulation, GraphModel
```

## تعديل لاحقًا
- الوسوم تُستخرج تلقائيًا من أي نص يبدأ بـ `#` داخل العنوان أو المحتوى — لا حاجة لأي
  إعداد إضافي، فقط استخدم `#اسم_الوسم` داخل ملاحظاتك
- لتغيير اسم التطبيق أو حزمة الحزمة (package name) عدّل `app/build.gradle.kts`
  (`namespace` و`applicationId`) و`AndroidManifest.xml`
